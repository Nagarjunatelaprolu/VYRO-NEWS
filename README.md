# VYRO NEWS Final Dynamic

## Includes
- Exact VYRO logo in header/footer
- Hero banner matching the requested layout: 1 big left card + 1 big center card + 2 small right cards
- Auto-sliding hero every 5 seconds
- Breaking-news ticker with controls
- Trending Now
- Andhra Pradesh / Telangana / Cinema / Sports sections
- VYRO News Videos
- Quick Updates
- VYRO Live Updates
- Poll of the Day
- News alerts
- Local demo content + local SVG images
- `/api/news` dynamic JSON API with GET/POST/PUT/DELETE

## Run
`npm install`
`npm start`

Then open the shown local URL.
